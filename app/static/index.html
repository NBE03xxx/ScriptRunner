    Script Runner ヘルプ

    指定フォルダーにあるシェルスクリプトを一覧・編集・実行するデスクトップアプリです。

    使い方

    • 「＋ 新規作成」で .sh ファイルを作成します。
    • 各項目の「Edit」で内容を編集し、「Run」でターミナルから実行します。
    • Tagで絞り込み、並べ替えで表示順を変更できます。
    • 「Delete」は確認後にスクリプトを削除します。削除は取り消せません。

    このアプリについて

    Script RunnerはGTK4とWebKitGTKを使用します。サービスはローカルで動作し、画面を閉じてもログイン中は稼働します。

    テーマは起動時にデスクトップの設定に合わせます。「テーマ切替」で、この画面のライト／ダークを手動で変更できます。

    スクリプトの削除

    この操作は取り消せません。
